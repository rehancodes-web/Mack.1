Technology

Seven free satellite and aviation datasets, a Node.js pipeline that reads only the pixels it needs, and Larper, a Random Forest that labels every 10 m of the airport. Rubric: Track A · Technical depth, AI & satellite data (20).

Pipeline

  1. 1FetchRead only the airport window from cloud-optimised GeoTIFFs; per-month scene manifest with direct band URLs.data/build_manifest.js
  2. 2CleanPer-scene scale and offset (checked against raw pixel values), cloud and shadow masking from the scene classification layer; cloudy months become gaps.a6/progress.mjs
  3. 3Features6 bands + NDVI, NDBI, water index, bare-soil index: 10 features per 10 m pixel.a6/classify.mjs
  4. 4ClassifyLarper Random Forest: built/paved, bare, vegetation, water, every month.a6/classify.mjs
  5. 5Decide12-month median of converted land vs reported milestones → release-or-inspect decision; Nemotron brief.a6/economics.mjs

Larper model card

Set-up

  • Random Forest, 20 trees, max depth 12, 70% features per split
  • Labels: ESA WorldCover 10m 2021 v200 (tile N27E075)
  • Training scenes: 2021-02, 2021-04, 2021-11 (three seasons, same year as labels)
  • Split: spatial: train west of footprint centre line, test east; footprint and 300 m buffer excluded
  • 10,483 training pixels, 8,585 test pixels

Stack and engineering

Stack

  • Node.js only (geotiff.js, proj4, ml-random-forest, pngjs)
  • Static site on GitHub Pages
  • NVIDIA Nemotron via API (key server-side only)

Problems solved

  • +1,000 DN offset differs between collections
  • 8-month catalogue hole, filled from a second catalogue
  • Large window reads throttled; bands read one at a time with retries

Reproduce

  • node data/build_manifest.js
  • cd a6 && node progress.mjs && node classify.mjs
  • node economics.mjs && node demo.mjs && node publish.mjs
